Thyroid Cancer Diagnosis Prediction Using Machine Learning About the Project
This project focuses on predicting thyroid cancer diagnoses by classifying patient records into two categories: **Benign and Malignant**. It uses approximately 212,000 patient records to develop and evaluate machine learning classification models
The main goal is to compare different machine learning algorithms, handle class imbalance, and identify an effective model for thyroid diagnosis prediction. Objectives
- Analyze and preprocess a large healthcare dataset.
- Perform Exploratory Data Analysis (EDA).
- Compare five machine learning algorithms.
- Handle class imbalance using SMOTE and SMOTEENN.
- Optimize the Random Forest classifier using GridSearchCV.
- Evaluate and compare model performance.

Methodology
 1. Data Preprocessing
Cleaned and prepared the dataset by handling missing values, duplicates, and categorical features.

2. Exploratory Data Analysis
Analyzed patient records, feature distributions, and relationships between variables.

 3. Model Development
Implemented and compared five machine learning classification algorithms.

 4. Handling Class Imbalance
Applied:
- **SMOTE:** Generates synthetic samples for minority classes.
- **SMOTEENN:** Combines oversampling with data cleaning to improve class representation.

 5. Hyperparameter Tuning
Used GridSearchCV to identify suitable hyperparameters for the Random Forest classifier.
